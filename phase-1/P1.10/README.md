## 2. Goal & Scope

Every parse step in `axiom-l1-rs` emits a BLAKE3 hash of the byte range it consumed, chained into a Merkle commitment tree. The BLAKE3 implementation is **HACL\*-verified**, not a generic Rust port. Merkle root reproducibility is bit-identical across runs.

This is the first **cryptographic** sub-phase. It sets the bar: every byte that flows through APKAXIOM is content-addressed by a hash whose implementation is mechanically verified by F\*.

### In scope
- HACL\* BLAKE3 bindings (`crates/axiom-blake3-hacl`)
- `CommitChain` API on the parser
- Merkle Patricia Trie for the commit chain
- Performance: BLAKE3 hashing does not bottleneck streaming throughput

### Out of scope
- Halo2 / zk-SNARK circuits (Phase 4).
- Poseidon2 (in-circuit hash, Phase 4).
- Signature verification crypto (P1.11/P1.16).

### Install commands

```bash
# F* (via opam)
opam install fstar

# HACL* (clone, build C output, no F* re-verify needed for use)
git clone https://github.com/hacl-star/hacl-star external/hacl-star
cd external/hacl-star/dist/gcc-compatible
make -j$(nproc)
# Outputs: libevercrypt.a / .so

# bindgen for Rust FFI
cargo install bindgen-cli
```

Disk: HACL\* + F\* combined ~ 2 GB. Build time on 4-core: ~ 30 min cold.
